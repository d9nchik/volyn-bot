Telegram-уведомления для подочереди Волыньоблэнерго 3.1

Подготовлено 24.11.2026. Это готовый к настройке проект; он ещё не развёрнут.

Что делает
- Проверяет текущие ссылки на графики сегодня/завтра через публичный API.
- Сверяет дату графика с записью архива, читает цветные ячейки подочереди 3.1.
- Присылает новый график и изменения только для этой подочереди.
- Напоминает при проверке, если до начала отключения осталось не более 30 минут.
- При неизвестном размере/сетке/цветах прекращает разбор и сообщает о проблеме.
- Не использует AI, платные API распознавания, браузер или обход капчи.

Развёртывание за $0
1. Создайте бота в официальном Telegram @BotFather командой /newbot.
2. Откройте нового бота и отправьте /start.
3. Создайте публичный репозиторий GitHub и поместите содержимое этой папки
   в корень репозитория, включая скрытую папку .github.
   В репозиторий не нужно добавлять токен или chat_id.
4. На компьютере выполните python3 setup_chat.py. Введите токен в скрытый запрос.
   Скрипт покажет chat_id личного чата. Для этого у бота не должно быть webhook.
5. GitHub -> Settings -> Secrets and variables -> Actions -> New repository secret:
   TELEGRAM_BOT_TOKEN — токен от BotFather;
   TELEGRAM_CHAT_ID — полученный chat_id.
6. GitHub -> Actions -> Check Volyn 3.1 -> Run workflow.
   Проверьте успешный запуск и получение первого сообщения в Telegram.
7. Далее workflow запускается на 7, 22, 37, 52 минуте каждого часа (UTC).
   В сообщениях время указано по Киеву.

Цена и ограничения
Стандартные GitHub-hosted runners бесплатны для публичных репозиториев:
https://docs.github.com/en/actions/concepts/billing-and-usage
В приватном репозитории расходуется месячная квота аккаунта: запусков здесь
около 2880 за 30 дней. Нулевая цена для приватного репозитория не обещается.
Отправка обычных сообщений Telegram бесплатна:
https://core.telegram.org/bots/faq

GitHub может задерживать или пропускать запуски по расписанию. Напоминание
может прийти позже или не успеть прийти до отключения. Уведомления — по графику,
а не по фактическому наличию напряжения. Новые графики отслеживаются на следующей
успешной проверке; при недоступности источника старый график не считается свежим.
GitHub отключает расписания публичных репозиториев после 60 дней без активности:
периодически проверяйте Actions и при необходимости включайте workflow снова.
https://docs.github.com/en/actions/reference/workflows-and-actions/events-that-trigger-workflows#schedule

Состояние хранится в Actions cache. При очистке/вытеснении кэша возможна повторная
отправка графика и напоминаний. Одновременные проверки сериализованы.
Формат PNG жёстко проверяется по текущему шаблону 1750x2250. Изменение шаблона
потребует обновления парсера. Перестановку подписей при сохранении той же сетки
парсер не распознает; тестовый график приложен для ручного сравнения.
Доступность источника из GitHub Actions ещё предстоит проверить при запуске.

Локальная проверка
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/python bot.py --dry-run

bot.py --dry-run читает источник, но не отправляет сообщения и не меняет состояние.
Для запуска без сети: bot.py --image tests/fixtures/2026-11-24.png
Тестовый график на 24.11.2026 для 3.1: 08:00–11:00. Это пример, а не текущий прогноз.
